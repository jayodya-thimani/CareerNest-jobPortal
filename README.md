# CareerNest – Job & Internship Portal

CareerNest is a web-based job and internship portal developed to connect job seekers with employers through a simple and user-friendly platform. The system allows students and job seekers to explore opportunities, while employers can publish job vacancies, manage listings, and review applications.

## 🚀 Project Overview

CareerNest aims to simplify the recruitment process by providing a centralized platform for job searching, job posting, and application management.

The project was developed as a group project using the MERN stack, with separate interfaces for students and employers.

## ✨ Key Features

### 👨‍🎓 Student / Job Seeker
- Browse available job and internship opportunities.
- View job details.
- Access the job-seeking interface to explore opportunities.

### 🏢 Employer
- Access an employer dashboard.
- Post new job and internship vacancies.
- Manage and update job listings.
- View applicants for posted vacancies.
- Manage application statuses.
- Manage employer profile information.

## ⚙️ Installation and Setup

### Prerequisites
- Node.js and npm
- MongoDB
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/jayodya-thimani/CareerNest-jobPortal.git
```

### 2. Navigate to the Project Folder

```bash
cd CareerNest-jobPortal
```

### 3. Set Up the Backend

```bash
cd backend
npm install
npm run dev
```

Configure the MongoDB connection and any required environment variables in the backend `.env` file according to the project's configuration.

### 4. Set Up the Frontend

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```

Open the local URL displayed by Vite in your browser to access the application.
